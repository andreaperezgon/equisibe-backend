# Equisibé · Backend

Parte del servidor de la tienda Equisibé. Gestiona cuentas, productos, pedidos, pagos de prueba y administración.

**Tecnologías:** Java 21, Spring Boot, Spring Security, JPA y MySQL.

## Documentación

Toda la documentación está en la **[Wiki del backend](https://github.com/andreaperezgon/equisibe-backend/wiki)**, con índice, instalación, arquitectura, API, manual y pruebas.

## Arranque

Con el entorno y las variables preparados según la wiki:

~~~bash
mvn spring-boot:run
~~~

Servidor local: http://localhost:8080 · [Repositorio del frontend](https://github.com/andreaperezgon/equisibe-frontend)
